# Performance improvements — 2026-11-11

## Images and navigation
- Session-only LRU replaces the 30-second private-photo TTL. Immutable photo IDs
  are pruned when a current wishlist snapshot removes them. Separate 32 MiB variant
  and 8 MiB original budgets (256 entries each) keep originals from evicting cards.
- Card photos lease a stable decoded blob URL. Unmount/re-entry reuses the URL,
  while ref-counted cleanup safely releases evicted resources after views detach.
  Session end clears all blobs/URLs and cancels active/queued requests. Stale fetch
  or decode completion cannot restore a cleared cache. BFCache pagehide is preserved.
- At most six private image fetches run concurrently; thumbnail queue+fetch have
  a 15-second deadline and originals 45 seconds. Existing retry UI remains.
- Wishlist/folder content loads 24 cards per page. Show more appends a new batch;
  it does not remount or hide earlier pages. Each batch still reveals together after
  its thumbnails settle, preserving the requested fade. The slowest image can still
  delay its own batch on a cold load, but not every page of a large collection.
- Detail galleries use the existing private 320/640/960 variants. Download retains
  the original. No new storage schema or public cache/Service Worker data caching.

The cache is not persistent across reload/sign-out, and memory pressure/eviction,
new photo IDs or a different size variant may require a download. It does not
promise unlimited device storage or bypass server authorization. Large collections
still retrieve the metadata snapshot; backend cursor pagination is a future change.

## Other audit findings
- Public root no longer imports SettingsMotion or SwipeToast. AppMotion and Toaster
  mount inside the authenticated AppShell, preserving motion preferences there.
- Local public production sample: initial JS 194 → 132 KB transferred, 616 → 437 KB
  decoded, 9 → 6 script requests. Local sign-in LCP 320 → 340 ms is sampling noise,
  not evidence of an LCP speedup. All route chunk gzip sum remains ~415 KB.
- Light Rays caps at 24fps and 300k pixels; sample draw calls 113 → 93 per 4 seconds
  desktop and 113 → 92 with CPU throttling. Main-thread time did not uniformly drop,
  and this is not a real phone/GPU/battery benchmark. Button backdrop blur is 12px.
- Profile background polling is 60s, with freshness/in-flight guards; real focus/
  visibility/online resumes still refresh immediately. Wishlist remains 30s so partner
  wish changes retain existing sync cadence; hidden/offline pauses remain.

## Discover
- Three fixed CSS columns; method metadata maps to icon actions in row order.
  Additional implemented methods append to subsequent cells/rows; no dummy third app.
- 256px transparent WebP is generated by scripts/optimize-discover-icons.mjs using
  installed sharp. PNG originals remain editable sources, not in-page src URLs.
  spin-wheel.webp: 8,668 bytes; instant-pick.webp: 6,204 bytes (~15 KB combined).
- Inner Spin/Pick actions remain text-only. Existing press spring and reduced motion
  remain. ICO is intended for app/favicon usage and gives no benefit to this grid.
